Чередование атрибутов без значений

Пример: Переключение состояния disabled

Объяснение работы кода:

Код elem.disabled = !elem.disabled работает следующим образом:
1. Оператор ! (логическое НЕ) инвертирует значение
2. Если elem.disabled = true, то !true = false
3. Если elem.disabled = false, то !false = true
4. Таким образом, каждый клик меняет значение на противоположное
